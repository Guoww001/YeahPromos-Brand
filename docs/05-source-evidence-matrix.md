# 素材证据矩阵

## 1. 证据处理规则

- 本矩阵覆盖 `pb_manual_images/` 中全部 **40 张**原框架图片，以及 `onboarding_images/` 中全部 **25 张** Amazon 商家入驻补充图片，共 **65 张**。
- 仓库公开，因此不上传原图，避免泄露图片里的邮箱、账号、付款与业务数据。
- 文件名仅用于追溯本地证据；若未来需要团队在线查看，应先制作去敏版本并单独审批。
- 手册上的红色说明是操作指引，不自动等于长期业务规则；例如“不要使用 Black List”已列为待确认决定。

## 5. 素材未证明但闭环必需的横切能力

以下标记 `P`，必须由业务确认，但不建议在框架中遗漏：

- 统一待办与深链接
- 数据来源、刷新时间、币种、时区与指标定义
- 加载、错误、部分成功、权限不足与并发冲突
- 长任务的通知/下载中心
- 危险操作的原因、影响提示和审计日志
- 表单未保存提醒与版本冲突
- 图表的数据表替代、键盘访问和响应式重排
- 角色模板、品牌范围和动作级权限
- 敏感字段脱敏、API 密钥一次性展示和账号邀请/MFA
