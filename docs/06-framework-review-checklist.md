# 框架确认清单

## 使用方法

请把每项状态从 `[ ]` 改为：

- `[x]` 同意
- `[-]` 暂不实现
- `[?]` 需要补充讨论

并把选择或说明直接写在该项下方。也可用仓库的 [Framework feedback](../.github/ISSUE_TEMPLATE/framework-feedback.md) 模板反馈。

## A. 范围与方法

- [ ] 本阶段只冻结站内功能框架，不建立桌面或高保真 Demo。
- [ ] 后续不同视觉方向必须共享同一页面、字段、状态、权限和核心任务。
- [ ] 本项目不包含商家站外官网/营销页。
- [ ] Amazon Attribution 等第三方后台页面不纳入 YeahPromos 站内实现，只定义集成和数据边界。
- [ ] 原始手册图片包含敏感信息，不上传公开仓库；若需在线证据则另做去敏版本。

## B. 顶层信息架构

- [ ] 使用任务导向顶层栏目：总览、招募与伙伴、活动、商品与推广资产、佣金与规则、数据与交易、财务、消息与通知、集成与设置。
- [ ] 伙伴发现下保留“达人”和“媒体”两个视图，共享流程但保留不同画像字段。
- [ ] Reports 的绩效、品牌、交易与 BRB 归入“数据与交易”。
- [ ] Creatives 和部分 Tools 重新组合为“商品与推广资产”“佣金与规则”。
- [ ] Newsletters 与站内信箱/通知归入“消息与通知”。
- [ ] Payments 与 Payment Methods 分离：前者是财务流水，后者是设置。
